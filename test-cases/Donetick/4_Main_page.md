## TC-MainPage-1 - Проверка функции Group by

### Priority

Низкий

### Steps

1. Открыть главную страницу
2. В верхнем правом углу нажать на левую кнопку "Sort and Group"
3. В разделе "Group by" поочередно применить фильтрацию "Smart", "Due Date", "Priority", "Labels"

### Expected Result

При выборе "Smart" фильтрация происходит по оптимальному режиму (по дате и приоритету)

При выборе "Due Date" - по установленным срокам, начиная с ближайших

При выборе "Priority" - по важности задач, начиная с Р1

При выборе "Labels" - группировка по меткам

## TC-MainPage-2 - Проверка функции Quick Filters

### Priority

Низкий

### Steps

1. Открыть главную страницу
2. В верхнем правом углу нажать на левую кнопку "Sort and Group"
3. В разделе "Quick Filters" поочередно применить фильтрацию "Anyone", "Assigned to me", "Available for me", "Assigned to others"

### Expected Result
При выборе "Anyone" показываются задачи, доступные кому угодно

При выборе "Assigned to me" - задачи, назначенные мне

При выборе "Available for me" - задачи, доступные для меня

При выборе "Assigned to others" - задачи, назначенные другим

## TC-MainPage-3 - Проверка функции Create Filter

### Priority

Низкий

### Steps

1. Открыть главную страницу
2. В верхнем правом углу нажать на левую кнопку "Sort and Group"
3. В самом низу нажать "Create Filter"
4. В открывшемся окне заполнить необходимые поля и создать условия фильтрации. Например, Condition 1: Field - Priority, Value - P1; Condition 2: Field - Status, Value - Active
5. Нажать "Save"

### Expected Result

До сохранения задачи видно Preview где предварительно показаны задачи с данным фильтром. После сохранения открывается главная страница. Слева в разделе Filters можно увидеть созданный фильтр и задачи, подходящие под него

Низкий

## TC-MainPage-5 - Проверка функции Enable Multi-select Mode

### Priority

Средний

### Steps

1. Открыть главную страницу
2. В верхнем правом углу нажать на правую кнопку 
3. В открывшемся окне протестировать функционал - кнопки "All", "Close", "Complete", "Skip", "Archive", "Delete". Кнопки "Complete", "Skip", "Archive", "Delete" доступны только после выбора одной или нескольких задач

### Expected Result
При нажатии на кнопку "All" происходит выбор всех существующих задач.
"Close" закрывает все окно.
"Complete" завершает задачу(и).
"Skip" пропускает задачу(и).
"Archive" архивирует задачу(и).
"Delete" удаляет задачу(и).
