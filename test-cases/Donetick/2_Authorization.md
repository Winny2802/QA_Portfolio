> ### TC-Auth-1

### Title

Успешная авторизация с валидными данными

### Priority

Высокий

### Preconditions

Пользователь зарегистрирован.

### Steps

1. Открыть страницу авторизации
2. Выбрать "Primary Account"
3. В поле "Username" ввести корректное имя пользователя
4. В поле "Password" ввести корректный пароль
5. Нажать Sign In

### Expected Result
Пользователь успешно входит в систему.
Открывается Dashboard/Chores page.

> ### TC-Auth-2

### Title

Авторизация с неверным паролем

### Priority

Высокий

### Preconditions

Пользователь зарегистрирован

### Steps 

1. Открыть страницу авторизации
2. Выбрать "Primary Account"
3. В поле "Username" ввести корректное имя пользователя
4. В поле "Password" ввести неверный пароль
5. Нажать Sign In

### Expected Result
Авторизация не выполняется. Появляется сообщение об ошибке. Пользователь остаётся на странице входа

> ### TC-Auth-3

### Title

Авторизация с пустыми полями

### Priority

Высокий

### Steps 
1. Открыть страницу авторизации
2. Выбрать "Primary Account"
3. Поля "Username" и "Password" оставить пустыми
4. Нажать Sign In 

### Expected Result
Отображается валидация обязательных полей.
Запрос на сервер не отправляется
