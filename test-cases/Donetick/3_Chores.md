## TC-Chore-1 - Создание новой задачи

### Priority

Высокий

### Steps

1. Открыть главную страницу
2. Нажать "Create new chore" (голубой крестик в левом нижнем углу)
3. Заполнить поле "Name"
4. Нажать "Create"

### Expected Result
Новая задача создается и появляется в списке

---

## ТС-Chore-2 - Проверка поля "Description"

### Priority

Средний

### Steps
1. Создать новую задачу
2. Заполнить поле "Name"
3. В поле "Description" описать задачу более подробно, используя все имеющиеся функции: жирный, курсив, подчеркивание, зачеркивание, нумерация, использование всех типов заголовков
4. Нажать "Create"

### Expected Result
Каждая функция корректно воспроизводится, текст меняется в зависимости от выбранного стиля. После создания задачи описание корректно отображается

---

## ТС-Chore-3 - Проверка поля Priority

### Priority

Средний

### Steps
1. Создать новую задачу
2. Заполнить поле "Name"
3. В поле "Priority" выбрать каждый из приоритетов (P1/P2/P3/P4/No Priority, по очереди)
4. Нажать "Create"

### Expected Result

После сохранения задачи выбранный приоритет отображается снизу от названия. По умолчанию, в зависимости от важности задача отображается в списке других задач выше или ниже (P1 - сверху, No Priority - внизу списка)

---

## ТС-Chore-4 - Проверка поля Labels

### Priority

Средний

### Steps
1. Создать новую задачу
2. Заполнить поле "Name"
3. В поле "Labels" выбрать "Add New Label"
4. В появившемся поле заполнить поля "Name" и "Color", нажать "Add Label"
4. Нажать "Create"

### Expected Result

После сохранения добавленная метка с названием и соответствующим цветом отображается снизу от названия задачи. Данную метку можно использовать в качестве дополнительного фильтра- при нажатии на нее выходит список из задач с данной меткой

Средний

## ТС-Chore-7 - Проверка поля Repeat

### Priority

Средний

### Steps
1. Создать новую задачу
2. Заполнить поле "Name"
3. В поле "Repeat" нажать галочку напротив "Repeat this task"
4. В появившемся окне выбрать частоту повторения (daily/weekly/monthly/yearly/adaptive/custom). Для частоты "custom" настроить повторение вручную
4. Нажать "Create"

### Expected Result
После сохранения задачи, частота повторения отображается корректно рядом с названием задачи. После выполнения задачи, срок автоматически меняется на настроенный срок

## TC-Chore-8 - Проверка поля Due Date

### Priority

Средний

### Steps
1. Создать новую задачу
2. Заполнить поле "Name"
3. В поле "Due Date" нажать галочку напротив "Give this task a due date"
4. В появившемся окне выбрать дату

### Expected Result
После сохранения задачи, установленная дата и время отображаются корректно рядом с названием задачи в виде оставшегося до срока выполнения времени - "Due in an hour/ Due in 1 day/ Due in a month"

## TC-Chore-9 - Проверка поля Task Window

### Priority

Средний

### Steps
1. Создать новую задачу
2. Заполнить поле "Name"
3. В поле "Due Date" нажать галочки напротив "Give this task a due date" и "Set a specific time" и  выбрать дату и время выполнения задачи (например, сегодняшняя дата 23:00)
4. В поле "Task Window" нажать на галочку напротив "Set earliest completion time" и выбрать число (это время, за сколько до установленного срока задача станет доступна для выполнения), (например, 2 часа --> задача станет доступной для выполнения в 21:00)
5. Нажать "Create"

### Expected Result
После сохранения задачи, при условии что время на момент тестирования менее 21:00, зеленая галочка для завершения задачи не будет доступна. Если время на момент тестирования 21:00 и более, зеленая галочка будет активна и задачу можно будет завершить

## TC-Chore-12 - Проверка работы кнопки "Approve" 

### Priority

Средний

### Preconditions

В списке задач существует задача, для которой установлено одобрение администратором (в поле "Approval Requirement" установлена галочка напротив "Require admin approval")

### Steps
1. Нажать на данную задачу в общем списке
2. Выходит окно задачи, нажать "Mark as done"
3. После этого появляется две кнопки "Approve" и "Reject" (функция доступна только администратору)
4. Нажать на "Approve"

### Expected Result
Задача выполняется и отправляется в архив
